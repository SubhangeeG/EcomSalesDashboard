# Power BI Dashboard Project

## Project Overview
Designed and developed an end-to-end interactive Power BI dashboard to track, monitor, and analyze e-commerce order trends and customer behavior.

## Key Features & Architecture
- Interactive Dashboard Design: Developed a dynamic Power BI report to track and analyze e-commerce order fulfillment and customer purchasing behavior.
- Data Modeling & Joins: Built relational data models connecting customer profiles and transaction records to enable seamless cross-filtering.
- Custom Slicers & Filters: Added interactive filters so users can click around and easily view specific data.
- Diverse Visualizations: Utilized standard charts, matrices, and maps to represent sales trends, category performance, and geographic metrics.
